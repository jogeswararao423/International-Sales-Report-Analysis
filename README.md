# 🌍 International Sales Report Analysis

## 📌 Project Overview
This project analyzes international sales data using Python. It performs data cleaning, preprocessing, visualization, and business insight generation using real-world sales data.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Structure
├── International_Sales_Report_Analysis.ipynb
├── International Sales Report.csv
├── README.md

## 📊 Key Analysis
- Sales Trend Analysis
- Top 10 Customers
- Top 10 Product Styles
- Size Distribution
- Gross Amount vs PCS Analysis

## ▶️ How to Run
1. Clone the repository.
2. Install dependencies:
   ```
   pip install pandas matplotlib seaborn
   ```
3. Open the Jupyter Notebook.
4. Run all cells.
